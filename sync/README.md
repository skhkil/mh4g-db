# MH4G 브라우저 세팅 동기화

기존 GitHub Pages 사이트는 유지하고, Cloudflare Workers + D1를 개인 세팅 저장 API로 사용합니다.

## 최초 배포 (사용자가 Cloudflare 계정에서 수행)
1. https://dash.cloudflare.com 에 무료 계정으로 로그인합니다. **Workers Free 플랜을 유지합니다.**
2. 로컬 PC에 Node.js 설치 후 이 저장소의 `sync/` 폴더로 이동합니다.
3. `npx wrangler login` 실행 → Cloudflare 인증.
4. `npx wrangler d1 create mh4g-sync` 실행 후 출력된 `database_id`를 `sync/wrangler.toml`에 입력합니다.
5. `npx wrangler d1 execute mh4g-sync --remote --file=./schema.sql` 실행.
6. `npx wrangler deploy` 실행 후 **https://...workers.dev** 주소를 복사합니다.
7. https://skhkil.github.io/mh4g-db 에서 우측 상단 **☁ 세팅 동기화** 클릭.
8. PC에서 Worker 주소 입력 → **새 연결 만들기** → 43자리 코드 복사.
9. 모바일에서 같은 Worker 주소와 연결 코드 입력 → **기존 코드로 연결**.
10. 이후 기기에서 저장하면 최대 약 45초 뒤에 서버로 반영되고, 다른 기기의 화면은 새로고침 후 표시됩니다.

## 주의
- 백엔드가 미배포된 동안 동기화는 **동작하지 않습니다**. 일반 로컬 저장은 정상 동작합니다.
- **연결 코드는 계정 비밀번호와 같습니다.** 코드 소유자는 세팅을 읽고 변경할 수 있습니다. 외부 공개 금지.
- 서버에는 코드 원문이 아니라 SHA-256 해시로 만든 식별자만 저장되며 내용은 평문 JSON입니다 (비밀번호·민감정보 저장 금지).
- 최초 연결은 장비 배열의 동명 ID 충돌을 복제 보존하며 제작 목록/보유 소재 충돌 시 현재 기기 우선입니다. 적용 전에 로컬 백업을 만듭니다.
- **다른 기기에서 동시에 수정했다면 자동 덮어쓰기를 멈추고 해결 버튼을 보여줍니다.** 사용자가 선택한 복원 방향에 따라 로컬 백업을 보존합니다.
- 매번 화면 데이터를 완전 실시간 렌더링하지 않으므로 다른 기기의 변경을 받은 경우 새로고침하세요.
- 무료 플랜의 D1/Workers 한도 초과 시 요청이 실패할 수 있으나, 무료 플랜을 유지하면 자동 과금은 발생하지 않습니다.
- 브라우저 데이터 삭제 전에 **연결 코드와 주소를 별도로 보관**하세요.
- 현재 최초 구현이며 실사용 PC/모바일 브라우저 E2E는 배포 후 수행해야 합니다.
