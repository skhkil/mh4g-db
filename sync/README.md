# MH4G PC·모바일 세팅 동기화

기존 GitHub Pages 시뮬레이터와 Cloudflare Workers + D1를 사용한다. **Cloudflare Tunnel과는 별개**이며, Worker 주소는 웹 앱에 고정되어 있다.

## 현재 배포 환경
- 시뮬레이터: https://skhkil.github.io/mh4g-db/
- Worker: https://mh4g-sync.skhkil.workers.dev
- 상태 확인: https://mh4g-sync.skhkil.workers.dev/health
- D1 binding: `DB` → `mh4g-sync`, 테이블 `sync_records`
- 최초 설정 이후 **Worker 재배포 없이 프런트엔드 변경만으로** 저장 이벤트 동기화를 개선했다.

## 사용
1. PC에서 시뮬레이터 → **☁ 세팅 동기화** → **새 연결 만들기**.
2. 43자리 연결 코드를 안전한 곳에 보관한다. 공개 금지.
3. 모바일에서 **☁ 세팅 동기화** → 코드 입력 → **기존 코드로 연결**.
4. 저장 세팅, 보유 호석, 발굴무기·방어구, 즐겨찾기, 제작 체크리스트/소재가 동기화된다.

## 동작 (2026-11-10)
- 장비 세팅 저장·삭제, 보유 호석/발굴장비 변경, 즐겨찾기/제작 기록 저장 직후 이벤트 발생.
- 짧은 연속 변경은 약 **0.4초**로 묶어 서버에 자동 업로드한다.
- 다른 기기는 **약 10초마다** 서버 변경 확인; 앱 탭에 돌아왔을 때도 즉시 확인한다.
- 다른 기기 변경 수신 후 **화면 자동 새로고침**. 입력 중이거나 동기화 창이 열려 있으면 작업을 방해하지 않도록 새로고침을 잠시 미룬다.
- 백그라운드 모바일 브라우저는 타이머가 제한될 수 있다. 탭을 다시 열면 확인한다.
- 서버 연결 실패 시 로컬 저장을 유지하며 다음 확인 시 재시도한다.
- 양쪽 기기에서 동시에 편집하면 무단 덮어쓰기를 막고 **충돌 해결**을 요구한다.
- 기존 저장 데이터와 연결 코드는 변경하지 않는다.
- 이는 웹소켓 푸시가 아닌 **저장 즉시 업로드 + 10초 폴링 방식**이므로 다른 기기에 0초 지연으로 표시되는 완전한 실시간 시스템은 아니다.

## 보안/주의
- 연결 코드는 비밀번호에 해당한다. 코드가 노출되면 클라우드 데이터에 접근할 수 있다.
- DB에는 비밀 코드의 SHA-256 식별자와 일반 JSON 세팅이 저장된다. 민감정보는 저장하지 말 것.
- 초기 연결 시 기존 로컬 데이터와 클라우드 데이터를 병합하고 로컬 백업을 남긴다.
- 무료 플랜 사용량 한도 초과 시 요청이 실패할 수 있다.
- 실제 PC·모바일 연동은 사용자의 환경에서 추가 확인 필요. JS 문법 검사와 GitHub 코드 반영은 확인함.
