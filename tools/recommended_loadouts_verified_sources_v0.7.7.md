# v0.7.7 추천 장비 국내 커뮤니티 근거

추천 장비 DB는 자동조합 엔진으로 생성하지 않는다. 실제 MH4G 국내 커뮤니티에서 교복/추천/대표 커스텀으로 확인되는 장비만 등록하고, 같은 장비가 여러 무기에서 범용적으로 쓰이면 각 무기 추천에 중복 등록한다.

## 확인 자료

- 하위 교복: 몬스터헌터 갤러리 `몬헌을 시작한 뉴비들을 위한 몬4G 교복 지침서 (하위편)`
  - https://gall.dcinside.com/board/view/?id=monsterhunter&no=24587
  - 재기 세트, 카브라 세트가 하위 검사 교복으로 직접 소개됨.
- 상위 교복: 몬스터헌터 갤러리 `몬헌을 시작한 뉴비들을 위한 몬4G 교복 지침서 (상위편)`
  - https://gall.dcinside.com/board/view/?id=monsterhunter&no=24815
  - 카브라S, 리오소울, 진오우U가 상위 교복으로 소개됨.
  - 리오소울은 방음주 5개 + 체력주 2개 예시로 고급귀마개를 띄우고 체력 감소를 제거하는 정석 장식주 예시가 제시됨.
- G급 교복: 몬스터헌터 갤러리 `몬헌을 시작한 뉴비들을 위한 몬4G 교복 지침서 (G급편)`
  - https://gall.dcinside.com/board/view/?id=monsterhunter&no=24935
  - 레기오스X, 디아블로X, 스타나이트가 소개됨.
  - 스타나이트는 대검을 제외한 대부분 검사 무기에서 범용성이 높고 조충곤에 특히 잘 맞는다고 설명됨.
- G급 대표 커스텀: 몬스터헌터 갤러리 `몬헌을 시작한 뉴비들을 위한 몬4G 교복 지침서 (G급+)`
  - https://gall.dcinside.com/board/view/?id=monsterhunter&no=25076
  - 미쿠미쿠미, 우카우카우, 바이바이카이저가 이름이 통용되는 대표 커스텀으로 소개됨.
- G급 무기별 구체 조합: 몬스터헌터 인벤 `[4G] G급 추천 방어구 (번역)`
  - https://www.inven.co.kr/board/mhf/3746/393
  - 우카우카우 계열 검사 범용, 대검 범용 몸통배가 커스텀, 자자미X 랜스/건랜스, G2 가드 랜스, G2 포술 건랜스, 자자미Z 관통 헤보 등을 구체적인 부위/스킬과 함께 제시.

## 현재 적용 원칙

- 검사 하위: 람포스(공격형), 카브라(방어형), 재기(밸런스형). 카브라/재기는 국내 교복 자료 직접 확인, 람포스는 사용자 피드백과 프로젝트 DB 스킬(공격력UP)을 교차 확인한 공격형 초반 선택지.
- 검사 상위: 리오소울(공격형), 카브라S(방어형), 진오우U(밸런스형).
- 검사 G급: 레기오스X, 스타나이트, 우카우카우를 범용 축으로 두고 대검/랜스/건랜스/차지액스 등은 국내 자료에서 확인되는 무기 특화 세트를 추가.
- 거너는 검사 교복 자료를 그대로 복사하지 않는다. 현재 국내 MH4G 자료에서 구체 구성이 확인된 HBG 자자미Z만 우선 등록하며 LBG/활은 검증 자료 확보 전까지 빈 추천으로 둔다.
- 카드의 `공격형/방어형/밸런스형`은 별도 슬롯 구분이 아니라 실제 발동 스킬 성격을 요약하는 태그다.
- 추천 카드의 `목표` 필드는 사용하지 않는다. 실제 `발동` 스킬만 표시한다.
- `시뮬레이터에서 보기`는 추천을 재계산하지 않고 해당 카드의 실제 방어구/장식주를 수동 시뮬레이터에 장착한다.
