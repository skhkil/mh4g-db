# 추천 장비 재설계 2차 감사 v0.7.7

## 요청 반영

- PC 추천 카드는 한 줄 3개 배치.
- 하위/상위는 세트 장비 3개 + 커스텀 장비 3개.
- G급은 무기별 4개 후보 유지.
- `자동조합에서 재계산` 제거, `시뮬레이터에서 보기`로 변경.
- 추천 상단 중복 프로필 카드/장황한 안내 문구 제거.
- 커뮤니티 외부 링크는 국내 몬스터헌터 인벤 자료로 교체.

## 데이터 감사

- 프로필: 42
- 추천 카드: 224
- 하위 세트: 42 / 하위 커스텀: 42
- 상위 세트: 42 / 상위 커스텀: 42
- G급: 56

## 문제점 / 수정

1. 이전 추천은 하위/상위 3개가 모두 자동조합 커스텀이어서 완성 세트 선택지가 없었습니다.
   - 실제 `armor_sets.json`의 5부위 완성 세트에서 진행도·검사/거너·목적(공격/방어/균형)을 기준으로 3개를 별도 선정했습니다.
2. `자동조합에서 재계산`은 추천 내용을 시뮬레이터에 넣지 않고 목표 스킬로 새 검색만 수행했습니다.
   - 추천 방어구 5부위/목표 스킬/장식주를 수동 시뮬레이터에 직접 입력하도록 변경했습니다.
3. 추천 화면에 출처 설명과 방법론 문구가 반복되어 정보 밀도가 낮았습니다.
   - 카드 본문 설명을 제거하고 실제 국내 근거가 있는 경우 짧은 `국내 참고 ↗` 링크만 표시합니다.
