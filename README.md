# MH4G DB + 스킬 시뮬레이터 v0.7.1

## v0.7.1 수정사항

- 시뮬레이터의 무기/머리/몸통/팔/허리/다리/호석 각 행에 해당 파츠의 스킬 포인트 기여량 표시
- 장비 자체 스킬 포인트와 장식주 포인트를 분리 표시해서 상단 기여량을 합치면 아래 총합과 맞도록 구성
- 몸통배가 사용 시 몸통의 실제 기여 포인트를 배수 적용해서 표시
- 장비 결과 상단 요약에 `파츠별 스킬 포인트` 열 추가
- 장비 결과의 `장식주` 행에는 전체 장식주 스킬 포인트 합계를 별도로 표시(몸통 슬롯 장식주는 몸통배가 반영)

## v0.6.8 변경사항
- 스킬 시뮬레이터의 수동 장비 계산 `무기` 행에 `무기 종류` 필터를 추가했습니다.
- `전체 무기 / 대검 / 태도 / 한손검 / 쌍검 / 해머 / 수렵피리 / 랜스 / 건랜스 / 슬래시액스 / 차지액스 / 조충곤 / 라이트보우건 / 헤비보우건 / 활` 중 하나를 먼저 선택하면 해당 종류의 무기만 검색 후보에 표시됩니다.
- 무기 종류를 바꾸면 현재 선택 무기가 다른 종류일 경우 무기와 무기 장식주 선택을 자동 초기화합니다.
- 선택한 무기 종류 필터도 장비 세팅 저장/불러오기에 포함됩니다.

## v0.6.7 변경사항
- 무기 DB 검색창 앞에 `무기 종류` 드롭다운 배치. 무기 종류 필터는 헤더 전역필터와 독립적으로 동작합니다.
- 상단 헤더의 `타입 / 등급` 드롭다운을 화면에서 제거했습니다.
- 방어구 등급을 **최초 제작 가능 진행도** 기준으로 전수 재판정했습니다.
  - 기존 문제: 원본 `m1/r1`은 RARE 1~4 묶음인데 RARE4의 상위 장비까지 일괄 하위 처리됨.
  - 수정: S 계열, 원본 아이템/갈무리/용인족 교환표의 소재 입수 등급, 확인된 RARE4 하위 예외를 함께 사용.
  - 2,876개 중 234개가 `하위 → 상위`로 보정됨.
  - 기본 디아블로 세트(RARE3)는 하위가 맞아 그대로 유지.
  - 마기르 RARE4는 머리/다리=상위, 몸통/팔/허리=하위로 부위별 판정.
- 판정 근거와 변경 목록은 `tools/armor_rank_audit.json`에 저장했습니다.

## v0.6.7 장비 결과 레이아웃 개선
- 장비 결과 패널 내부의 가로/세로 스크롤 제거
- 결과 표를 패널 폭 100% 안에서 고정 레이아웃으로 표시
- 효과 설명은 좁은 열에서 자동 줄바꿈
- 포인트 열 제목/값을 같은 고정 열에 중앙 정렬

## v0.6.7 UI 가독성 개선
- 검색형 드롭다운은 한 번에 하나만 열립니다. 다른 검색 박스를 누르면 기존 목록이 자동으로 닫힙니다.
- 호석 스킬 목록은 설명을 제거하고 스킬명만 가로 한 줄로 표시합니다.
- 장식주 검색 목록은 넓은 팝업으로 표시하며 명칭/슬롯/포인트가 세로로 깨지지 않게 했습니다.
- 장비 결과의 `스킬 계통`과 `발동 스킬`은 줄바꿈을 억제해 가로로 표시합니다.

## v0.6.7 스킬 결과/검색 개선
- 장비 결과 스킬 포인트 상태: 발동 초록 / 미달 주황 / 음수 빨강
- 결과표 4열: 스킬 계통 / 포인트 / 발동 스킬 / 실제 효과
- 미발동 스킬은 다음 발동 포인트와 다음 효과 표시
- 장식주 검색, 호석 스킬 검색, 자동조합 목표 스킬 검색에서 발동명/효과 문구까지 검색
- `회심` 검색은 회심 관련 스킬과 사용자 편의를 위한 통격(약점특효) 관련 후보도 노출. 단 MH4G 약점특효 실제 효과는 육질 45 이상 부위에 육질 +5로 표시
- 스킬 결과 제목/행 정렬 고정


## v0.6.7 레이아웃 수정
- `원하는 스킬`과 `자동 조합 검색`을 다시 하나의 패널로 결합했습니다.
- 이 통합 패널 전체를 수동 장비 계산/장비 결과 아래쪽에 배치했습니다.
- 스킬 선택 → 선택 스킬 칩 → 검색 옵션 → 조합 검색 → 결과가 같은 영역에서 이어집니다.


## 이번 버전 변경
- 자동 조합 검색을 시뮬레이터 맨 아래 위치로 복원
- 수동 장비 계산을 2줄형 컴팩트 카드로 변경
  - 1줄: 무기/방어구/호석 선택
  - 2줄: 슬롯 현황 + 장착 장식주 + 장식주 검색 추가
- 수동 장비 계산 : 장비 결과 비율을 6:4로 변경
- 기존 실제 MH4G DB와 세팅 저장/불러오기 기능 유지
- `run_site.bat`은 빈 포트를 자동 선택하며 캐시를 비활성화
