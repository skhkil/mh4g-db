# MH4G DB + 스킬 시뮬레이터 v0.7.7


## v0.7.7 4차 작업 — 퀘스트 비고/요약 UI 정리

- 기준 파일 정책: **1번 프로젝트 원본을 수정 대상**으로 사용하고, **2번 Athena Data DB / 3번 MH4U DB는 비교·검증용 참조 데이터**로만 사용했습니다.
- 퀘스트 `이벤트 / 에피소드 / 다운로드 챌린지`의 비고에서 제작·검증 과정에만 필요한 내부 문구를 제거했습니다.
  - 예: `비공식 번역`, `DB 수치 프로필 후보`, `미확인 대상은 추측하지 않음` 등 사용자에게 불필요한 메모
- 이벤트/에피소드 퀘스트는 MH4U DB에서 확인 가능한 경우 **주요 보수 아이템**과 **해당 아이템을 재료로 사용하는 장비/아이템 사용처**를 비고에 추가했습니다.
- 에피소드 비고는 기존 식별 문구인 **`에피소드: xxxxx`를 유지**했습니다.
- 다운로드 챌린지 24개는 제공 MH4U DB의 `arena_rewards`에서 대응 보수 행을 확인할 수 없어, 보수 아이템을 추측해 추가하지 않고 기존 내부 검증용 비고만 제거했습니다. 퀘스트 표의 목표·보수금·인원/지정장비 조건은 유지했습니다.
- 퀘스트 메뉴의 **`여단 요약` / `집회소 요약` / `G급 요약`** 항목과 관련 진입 로직을 제거했습니다.
- 몬스터 메뉴의 **`육질표 요약`** 항목과 관련 진입 로직을 제거하고, 몬스터 기본 진입 화면을 **육질표 상세**로 변경했습니다.
- 검증: 프로젝트 JSON 파일 파싱 및 `app.js` 문법 검사를 수행했습니다.
- 이 항목부터는 **기능·데이터 수정이 발생한 모든 작업에서 README와 WORK_STATUS를 함께 갱신**하는 것을 릴리스 절차로 적용합니다.

### v0.7.5 방어구 3자 교차검증 및 보정 완료

- 방어구는 **현재 MH4G DB ↔ 사용자 제공 Athena 데이터 ↔ MonsterHunter4UDatabase** 3자 대조로 검증했습니다.
- **`maxDefense`와 `upgradeDefense`는 강화 기준이 다르므로 비교/수정 대상에서 완전히 제외**했습니다. 최종 검증 결과 두 필드는 **변경 0건**입니다.
- 한국어 장비명, 소재명, 랭크, 가격은 그대로 유지했습니다.
- 일본명 누락 **995개를 복원**하고 기존 일본명 오타/깨짐 **37개를 정정**했습니다. 일본명 미기재는 1,028개 → **33개**로 감소했습니다.
  - Athena 한국어 행과 MH4U 일본명/부위를 독립적으로 확인한 매칭을 우선 사용했습니다.

- 두 외부 소스가 **같은 값으로 일치한 경우에만** 실제 수치를 보정했습니다. 총 209개 방어구에서 296개 필드가 수정되었습니다.

  - 슬롯 7
  - 성별 77
  - 화내성 17 / 수내성 12 / 뇌내성 56 / 빙내성 76 / 용내성 15
  - 스킬 구성/포인트 31

- 외부 두 소스가 서로 다른 항목(검사/거너, 일부 기본방어력/스킬/내성/슬롯)은 **자동 덮어쓰기하지 않았습니다**.
